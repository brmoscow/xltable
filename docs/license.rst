License Agreement
=================

XLTable is licensed under the End User License Agreement below. The same
text ships as ``EULA.txt`` in the root of every distribution: the Windows
installer shows it before installing, the Linux installer prints it and
asks for acceptance on a fresh install (``--accept-eula`` answers it for
unattended installs), and the portable zip carries it next to
``XLTable.exe``. By installing or using XLTable you accept it.

The open-source components bundled with XLTable and their license texts are
listed in ``THIRD-PARTY-NOTICES.txt`` in the same folder.
